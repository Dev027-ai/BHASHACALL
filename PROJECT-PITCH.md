# BhashaCall
### Making multilingual voice communication more accessible

**Project:** BhashaCall  
**Challenge:** The Great Indian AI Internship Challenge — Gnani AI  
**Developer:** Devansh Sharma

## The Problem

India's linguistic diversity creates communication barriers when people speak different languages or prefer interacting through voice rather than text. Accessing written information can also be difficult for people who would rather listen.

## Our Solution

BhashaCall is a multilingual voice communication prototype that brings speech recognition, language translation, speech synthesis and document listening together in one application.

The goal is to make it easier to convert spoken input into understandable translated output and turn supported documents into audio that users can listen to.

## Key Features

- **Speech Recognition:** Converts spoken input into text using integrated speech technology.
- **Language Translation:** Connects speech transcription to a separate translation layer.
- **Text-to-Speech:** Generates spoken output from text using integrated speech synthesis.
- **Document Listening:** Processes supported documents and provides an audio listening workflow.
- **Voice-first Experience:** Brings these capabilities together through a single application interface.

## Technology

- Python backend
- Web-based frontend
- Gnani AI speech technology for speech recognition and speech synthesis
- Separate translation service
- API-based integration between application components

## Expected Impact

BhashaCall explores how voice AI can help make multilingual communication and access to information more convenient for students, everyday users and people who prefer spoken interaction.

The project focuses on the potential of AI built for India's diverse language ecosystem.
